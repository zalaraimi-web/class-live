خطوات وضع Class Live على الإنترنت برابط ثابت
=============================================

١) GitHub
   - سجّلي حساباً مجانياً في github.com
   - اضغطي + ثم New repository، الاسم: class-live، ثم Create repository
   - اضغطي "uploading an existing file"
   - افتحي مجلد class-live، حدّدي كل ما بداخله (Command + A) واسحبيه للصفحة
   - اضغطي Commit changes

٢) Render
   - ادخلي render.com واختاري Sign in with GitHub
   - اضغطي New ثم Blueprint ثم اختاري class-live
   - سيطلب TEACHER_PASSWORD: اكتبي كلمة مرور تختارينها لشاشة المعلمة
   - اضغطي Deploy وانتظري حتى تظهر كلمة Live

٣) الروابط
   - شاشة المعلمة:   الرابط الذي يعطيك إياه Render (ينتهي بـ onrender.com)
   - شاشة الطالبة:   نفس الرابط + /play
   - رمز QR على السبورة يأخذ الرابط الصحيح تلقائياً

ملاحظات
   - افتحي شاشة المعلمة قبل الحصة بدقيقتين (الخطة المجانية تنام عند عدم الاستخدام)
   - الطالبات لا يحتجن كلمة مرور ولا حساباً
   - الاختبارات الدائمة ضعيها كملفات في مجلد quizzes على GitHub
